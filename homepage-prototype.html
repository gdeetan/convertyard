How It Works

Three steps. Zero uploads.

01
Drop your files
Click or drag, one file or a thousand. Mobile, desktop, doesn't matter.
02
Convert in your browser
Real WebAssembly does the work. Your files never leave your device.
03
Download
Single file or a ZIP with all of them. Ready in seconds.
Wait — how is this possible without uploading?
WebAssembly lets us run the same battle-tested C++ libraries that desktop apps use (libvips, ffmpeg, pdf-lib) directly inside your browser. The same kind of code that powers professional desktop tools runs in this tab, on your CPU, without sending your file anywhere.
