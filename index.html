Wait — how does it work without uploading?

WebAssembly lets us run the same C++ libraries that desktop apps use (libvips, ffmpeg, pdf-lib) directly inside your browser. The same code that powers Photoshop's CLI runs in this tab, on your CPU, without sending your file anywhere.
