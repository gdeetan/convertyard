# Cluster 06 — Web & Brand Utilities

## Seed keyword

**Primary seed:** `web design tools`

Hub page targets this. Individual tools target specific operations.

**Why this seed:** Captures the cluster identity for designers,
marketers, and devs assembling brand assets.

**Alternate seed:** `free brand tools` — narrower, lower volume,
softer SERP.

- `favicon generator` (~40K vol, KD ~45)
- `qr code generator` (~500K vol, KD ~65)
- `og image generator` (~10K vol, KD ~35)
- `color picker` (~80K vol, KD ~50)
- `hex to rgb` (~60K vol, KD ~45)

## Cluster priority

**#6** — Build later. Volume is fragmented across many small tools.
Use this cluster to fill out the site after the high-priority
clusters mature.

**Exception:** Favicon generator is high-priority. The dominant tool
(realfavicongenerator.net) is slow and over-engineered. A modern,
fast alternative could capture significant traffic quickly.

## Wedge-specific notes

- **Local-first applies but doesn't drive the choice as strongly.**
  Nobody is afraid of uploading a logo to make a favicon. Lean less
  on privacy messaging here, more on **speed, clean UI, and modern
  defaults**.
- **OG image generator is a real gap.** Most existing tools just slap
  text on a gradient. A version that lets users design proper
  templates (with brand colors, fonts, layout) would stand out.
- **Favicon generator** should output every size needed in 2026
  (16, 32, 48, 96, 144, 152, 167, 180, 192, 512, plus SVG) and the
  HTML snippet to drop in. Realfavicongenerator does this but slowly
  and with a 5-screen UI.

## SERP context

- QR code generator dominated by qrcode-monkey, QR-Code-Generator.com,
  and Bitly — head term, very hard to rank, low ROI
- Favicon generator has a clear weak incumbent — winnable
- Color and CSS tools are dominated by CSSGradient.io, ColorZilla,
  Coolors — entrenched but beatable on speed

## Watch list

- Browser-native APIs replacing some of these tools (e.g., the
  Native CSS gradient editor in DevTools) — focus on tools that
  add value beyond what dev tools provide
- OKLCH and the new CSS color space proposals — early content
  ranks here before incumbents update
